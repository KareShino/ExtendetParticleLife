# 拡張 Particle Life (Windows / C++)

種類ごとの弱い力(元の Particle Life)に、価数つきの強い結合(バネ)を加えた 2D 粒子シミュレータ。
Dear ImGui + OpenGL 3.3 + GLFW、静的リンクで DLL 不要の単一 exe。

## ビルド

必要なもの: Visual Studio 2022 以降(「C++ によるデスクトップ開発」ワークロード。CMake 同梱)、インターネット接続(初回のみ依存ライブラリを自動取得)。

```bat
build.bat
```

または CMake が PATH にある場合:

```bat
cmake -B build
cmake --build build --config Release
```

出力: `build\Release\ParticleLife.exe`(単体で動作。プリセットは exe と同じフォルダの `presets\` に保存)。
引数で初期粒子数を指定可能: `ParticleLife.exe 8000`

## 画面

- 左: プレビュー(ワールドは 1×1 のループ空間)
- 下: 粒子数の上限、配置モード(手動 / ランダム)
  - 手動: 種類を選び、左クリックで1個、左ドラッグでブラシ範囲に連続配置、右ドラッグで消去
  - ランダム: 種類ごとの比率を指定し「一括生成」(全消去して上限数まで生成)
- 右: 弱い力テーブル(非対称、プリセット保存/読込・ランダム生成)、結合可否テーブル(対称)、価数テーブル(種類の削除)、共通パラメータ、表示設定

## モデル

- 弱い力: `r = 距離/最大距離` として、`r < β` で共通斥力 `r/β − 1`、`β ≤ r < 1` でテーブル値 `a` による山形 `a·(1 − |2r − 1 − β|/(1 − β))`。合計に `最大距離 × 力の倍率` を掛ける。結合済みペアには引力側(正の値)を働かせない。
- 結合: 結合距離以内・両者の価数に空き・結合可否テーブルが可、のペアが 1 ステップあたり結合確率で結合。バネ力 `バネ強度 × (距離 − ボンド長)`。切断距離超過、または切断確率で切断。粒子あたり最大 4 スロット。
- 熱ゆらぎ: 各ステップで速度にランダムな揺らぎを加える。
- 摩擦: 速度の半減時間で指定。
- 近傍探索: 端でつながる一様グリッド。力計算は自前スレッドプールで並列化(OpenMP は vcomp DLL が必要になるため不使用)。
- 種類色: 種類 ID × 30° の色相、彩度・明度は共通。種類を削除すると後ろの ID が詰まり、色も ID に従って変わる。
- プリセット読込時、種類数はプリセットに合わせて増減する。
